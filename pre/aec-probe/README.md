# AEC 参考流试验

此探针只记录，不执行声学回声消除（AEC），也不改变 DSP 输出。只在隔离的 ALSA 运行实例中启用，不用于日常服务。音频内容可能含人声；只录获准采集的素材，不将轨道提交到仓库。

## 采集与对齐

1. 准备隔离配置，使用独立 `run_dir` 和专用采播设备。不要设置 `capture_file`。声学场景首次试验使用耳机或低播放增益，先确认没有啸叫风险。
2. 用带 `--aec-probe <新目录>` 的 `mozart-pre --socket <控制套接字> --config <配置>` 启动实例。若需由测试 daemon 监管，用独立启动包装器追加该参数，不修改正式服务。每次启动使用未存在的新目录。
3. 按场景播放和录音；每轨最多接收约 60 s 的样本。先结束采集，再用 `SIGTERM` 停止 `pre` 或经其测试 daemon 正常停止。以 `summary.json` 检查采集、时间戳无效和诊断队列丢失计数；没有完整摘要时不评分。
4. 在本机用 Python 和 NumPy 导出对齐轨道：

   ```bash
   python3 -B pre/aec-probe/align.py <探针目录> <新输出目录>
   ```

5. 检查 `alignment.json` 的覆盖比例、拟合残差、时钟相对速率和所选区间。保留 `mic.wav` 和 `reference.wav` 作同一条件的离线 AEC 输入。默认不补偿额外声学路程；仅在已知该延时时使用 `--delay-ms`。

每次读写后取一次同步 ALSA 状态快照，只记录实际传输的首声道 PCM。时间戳使用单调时钟，记录包括 ALSA delay；它不是直接硬件 ADC／DAC 对拍。诊断队列为固定大小；队列满时保留样本序号缺口。写盘在普通线程，探针关闭时既不取状态快照也不写盘。开启探针会增加驱动调用，不用它验收生产实时延迟。

离线工具对每段拟合设备的样本时钟。按设备切换、ALSA 恢复、探针丢失和无效时间戳切段；额外识别超过 5 ms 的时钟位置跳变。拒绝超过 2 ms 拟合残差 p95 或名义采样率偏离超过 2000 ppm 的段。只导出最长连续交集；不跨缺口补样。播放端排除未能确认已经离开队列的尾部。

本机回环结果及声学试验条件见[报告](../../reports/aec-reference-20261123/RESULTS.md)。
