# 新控制台首轮实现

前端已完成 Vue 组件拆分、新接口接线和浏览器契约检查。
本轮交付 `web/`，不包含 Rust HTTP 适配器；真实服务接入按 SPEC-06 的提供方待办推进。
后续适配器实现与板端实测见 [2026-11-17 报告](../web-adapter-20261117/RESULTS.md)。

## 实现

- 沿用旧控制台的亮暗设计令牌与三栏布局，窄屏自动改单栏。
- 系统启停、路由、静音、服务重启均调用 daemon 的 HTTP 映射，不在浏览器编排播放设备。
- 期望路由与实际路由分开显示；失联时禁用业务写操作。
- 文件直接提交入队，受理与完成分开；结果按 job_id 下载并检查 WAV 响应。
- 设备显示当前设备、TOML 基线和未应用选择，写入后不自动重启。
- 参数逐项显式应用，不暴露旧 filter_radius；板端已有单模型 default 预设命令，HTTP 映射按 SPEC-06 待办接入。
- 字幕按身份与修订号合并，命名 SSE 支持 reset 和带游标重连；窗口外旧修订不抢占当前句。
- 写入结果未知时，提示独立保留；只有未知结果产生后发起的队列查询成功，才允许用户确认并再次提交。
- 补测发现并修正了复选框与路由拒绝后的假状态、状态查询与 SSE 竞态，以及重连时提前清除业务错误。
- 音色上传、试听及术语编辑显示未接入提示，不提供虚假可执行入口。
