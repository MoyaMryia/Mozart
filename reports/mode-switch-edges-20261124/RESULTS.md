# 输出模式切换故障注入

## 结果

| 故障或切换顺序 | 验收结果 |
| --- | --- |
| 启动时已隔离播报，TTS 不启动 | 直出与变声往返生效；播报不误报生效。取消未开启的播报后仍能切变声，ASR 启动号不变。 |
| `RVC → 直出 → RVC → 直出`，旧实时停流已执行但应答丢失 | 租约未确认前不再起流；重复 `RVC` 意图保留等待槽。最后的直出取消等待意图。恢复应答后仍只有初始一次起流。 |
| bridge 已开启播报，但开启应答丢失；随后请求直出 | 状态不误报播报生效；下一次直出先撤权。注入 TTS 停止故障时，不误报直出已生效；恢复应答后完成。 |
| 实时变声静音期间重启 pre，同时拒绝 RVC 状态请求 | 新 pre 保持静音等待；daemon 报告 `reattaching_playout`、未应用。RVC 恢复后，先确认实际播放边界，再恢复变声与静音策略。 |
| 从静音或独占播报恢复实时，以及两条实时路由交错 | 单测验证打开前已选定目标源，没有兜回默认原声；有声旧路由尚未淡出完成时不提前确认新路由。 |

daemon 语言链用例连续运行三轮，每轮 11 项。原有三态往返、pre／bridge 重启、文件租约归还和旧代播报丢弃回归继续执行。命令入口、状态与实现在 [模式转移表](../../docs/MODE-TRANSITIONS.md) 中定义。

## 适用范围

x86_64 本机，真实 daemon 配协议桩；每个新增故障是一组用例。PCM 选源另用确定性音频单测。未在 Jetson 执行真实音色负载和声卡切源；需要独占设备窗口后验证音频中断、延迟和欠载计数。本轮未部署。
