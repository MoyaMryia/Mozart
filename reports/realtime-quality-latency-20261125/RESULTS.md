# 实时变声质量与延迟分步优化实测：Jetson

日期：2026-11-25。对象：实时变声链路分步自然度优化、`IndexSearch` 加速、同机 `--fp16` TensorRT 引擎与 `160 ms` 短块实验。
设备：Jetson Orin Nano Super 8 GB（`MAXN_SUPER`），JetPack 6，TensorRT 10.16。
基线提交：`20e9700`（已包含 `pre` 20 ms 等帧与 2176 样本 ALSA 采播缓冲修复）。

## 适用范围

- 覆盖：
  1. **确定性四相位锁死直驱对照**（经 `rvc.sock` / `rvc-in.sock` / `rvc-out.sock` 直驱 `mozart-rvc`，固定 0/60/120/180 ms 四个块网格相位取均值、零欠载步进，彻底消除 `aplay` 随机相位噪声，用于严苛验证每步算法是否真正提升）；
  2. **完整三进程 ALSA `snd-aloop` 物理回环实测**（端到端净延迟、30 s 中文人声、60 s 长跑稳定性、48 kHz `bocchi-v2-48k` 与 40 kHz `tomori-v2-40k` 跨采样率验证）。
- 未覆盖：物理 USB 麦克风实录、32 kHz 主观听感、`160 ms` 短块跨多模型全量重建。

## 四、关键根因总结

1. **启动缓冲硬下界 $D_{\min} = W + T_{\text{infer,max}}$**：在原始 FP32 `177 ms` 推理下，单纯调小 `startup_delay_ms` 至 `320/280/240/200 ms` 净延迟仍锁在 `582 ms`，`pre_gap_frames` 线性增至 `6~10`；必须先压缩 $T_{\text{infer}}$ 或 $W$ 才能获得零缺帧延迟收益。
2. **隐藏的 `88.6 ms` CPU 索引检索瓶颈**：`IndexSearch::search()` 原为单线程标量 L2 扫描且逐帧重读 10.9 MB 质心表。优化为 AArch64 NEON 向量化 + 32 帧质心分块 + 4 线程并行后降至 `6.0 ms`（14.8× 提速），与标量参考精确一致（`max_diff < 1e-4`）。
3. **Step 3 回滚与额外提速**：四相位锁死消融证明 Step 3 绝对网格初相/噪声与 `3e-3` SOLA 门限均造成真实声学退化并多耗 `4.9 ms/块` CPU；回滚后不仅恢复并超越 Step 1 音质，还将 240 ms FP16 推理压至 `56.0 ms`（P95 `60.7 ms`），解锁了 **`d=300 ms` 零缺帧（净延迟 `435.3 ms`）**。
4. **`160 ms` 短块暂不切默认**：虽然把净延迟压至 `365.6 ms` 且通过 60 s 零缺帧长跑，但存在轻微声学代价（Log-Mel `+0.11~0.23 dB`、接缝 6.25 vs 4.17 缝/s）且破坏既有 240 ms 资产兼容，保留数据供后续多 profile 动态几何阶段接入。
