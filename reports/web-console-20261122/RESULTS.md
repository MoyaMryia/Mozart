# Web 控制台主线迁移与复核

## 结论

已将保存的 Vue 控制台和独立 Rust HTTP/SSE 适配器迁移至主线 `1136d38`，保留已合并的增强与 ASR 改动。
本次分支为 `feature/web-console`。原始 stash 和仓外备份保持不变，不包含无关音频研究。

本轮完成当前提供方支持的控制台操作、模型选择及单 default 预设；不把这些操作称为完整 v1 产品验收。
历史板端真实推理证据见[适配器报告](../web-adapter-20261117/RESULTS.md)，本轮新增本机验证不替代该报告中的板端复测欠账。

## 完成内容

- 系统启停、路由、静音、服务重启、设备配置、参数、翻译和播报开关、文件队列与下载。
- 增强进程状态、工作计数和错误展示，以及 daemon 统一编排的增强重启。
- `PUT /api/v1/model` 透传 `ModelUse`，模型列表失效或模型缺失时禁止提交。
- `GET /api/v1/preset` 读取当前模型的单 default 预设；两个 POST 操作分别保存和使用预设。
- 状态流与字幕流共享读取；字幕按身份和修订号恢复，保留 reset、游标和背压规则。
- 写入结果未知后，相关分区保持禁用。旧 HTTP 请求和 SSE 不代替结果未知之后的新 HTTP 状态查询。
- 设备配置的未知结果还要求重新读到相关基线。确认函数与按钮使用同一条件，不自动重试写入。

## 审查修复

1. 上传根目录不再无条件 chmod。拒绝符号链接、非当前用户所有和非私有的现有目录。
2. 文件缓存驱逐只处理队列快照中已知任务的指定产物，保留未知文件与符号链接，并向状态上报访问错误。
3. 驱逐／提交并发回归使用真正已登记的终态旧任务，不删除生产保护条件以满足旧夹具。
4. 模拟上传 peer 原子发布完整 JSON，消除测试读取半文件的竞态，不串行化测试或增大预算。
5. HTTP JSON 体必须是对象，空数组不能冒充空请求。
6. 列表／预设读取失败后禁止依赖旧值写入；结果未知必须经重新查询和显式确认。
7. 部署前源码不存在时，失败回滚将新源码移入事务记录，恢复原先不存在的状态，不假报恢复。
8. Web 服务状态查询不改变共享运行目录权限。
9. 翻译重试的进程测试在原 5 s 预算内同时等待翻译和异步播报提交；全部原断言保留，连续三次通过。

部署入口保留事务锁、源码和程序备份、静态资源回滚、低端口 capability 清除及独立 Web 生命周期。
增强程序纳入安装、停机检查和就绪检查；构建前暂停整栈，安装后完整启动。

## 真实本机适配器／daemon 浏览器联调

使用独立 `/tmp` 配置、真实 adapter、daemon、ctl，以及 pre／RVC 协议桩。
浏览器访问生产构建，不使用模拟 HTTP 服务。16 个阶段全部通过：

- 页面可达、启动、模型列表、选择模型、保存预设、使用预设。
- direct／RVC 路由、静音／取消静音。
- 同一字幕身份从 revision 1 更新至 2，正文更新且 DOM 节点身份保持。
- 断开 EventSource 后持游标重连，取得新增话语身份与事件 ID。
- 按正常仲裁先转 direct 并确认 GPU owner 为空，再上传 WAV、等待完成和实际下载。
- daemon down 后，页面与适配器 health 仍可达，业务 status 返回 503；随后 up 恢复。

下载校验 RIFF／WAVE 标记和长度，实际文件为 192,114 bytes，SHA-256：

```text
87934dafa2ad8474bde769ae8efa07cddf5260c37e0e399e2d6ec9ef5303d77b
```

早期夹具失败均保留：每次追加关闭描述符触发合法 generation reset，故不满足稳定 DOM 的夹具前提；未释放实时 GPU 导致文件排队；相对下载 URL 不能由 Node 直接解析。
最终夹具使用与 bridge 一致的持续打开描述符，并正确释放 GPU。未放宽身份、正文、完成条件或等待预算。
