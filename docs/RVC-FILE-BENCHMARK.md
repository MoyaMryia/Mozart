# RVC 文件链路基准

定义文件链路（`kind=file`）分窗质量的验收指标与消融方法。

## 1 范围与基线

适用路径：FileWorker → `RVCInferencer::infer`（`rvc/src/rvc/inferencer.cpp`）。

固定参数，隔离分窗变量（沿用 `reports/multi-model-file-20261115` 默认）：

- `pitch_shift=0`、`index_rate=0`、`rms_mix_rate=1.0`、`protect=0.33`、`denoise=false`、`f0_method=rmvpe`。

输入时长矩阵：10 / 30 / 60 / 120 s。

基线按生成器形态分，不共用一条：

| 形态 | 引擎特征 | 单窗基线 |
| --- | --- | --- |
| 动态 | feats 时间轴动态，含 `latent_noise` | Mozart 自身整段单窗（帧数 ≤ max profile） |
| 静态整段 | 固定大 T | Mozart 自身单窗 |
| 静态定长 T=200 | 固定 T=200 | 无单窗路径；用整段导出或 Golden PyTorch |

用 Mozart 自身单窗做受控基线，是为了分离「分窗代价」而非「搬移误差」。动态噪声模型的 C++ 与 PyTorch 随机序列不同，无法逐样本对 Golden（代码确认，`inferencer.cpp:890` 固定种子；`reports/multi-model-file-20261115` 已记录），故对 Golden 改用质量指标而非波形相关。

静态定长 T=200 的整段导出基线见 `reports/rvc-fulllength-golden-20261113`。

## 2 四层指标

### 2.1 契约与运行状态（必须过）

| 指标 | 抓什么 | 建议 |
| --- | --- | --- |
| `state=completed` | 任务是否跑完 | 必须 |
| `frames_in == frames_out` | 数据面帧守恒 | 必须 |
| 输出样本数 / 时长 | 是否按输入时长收口 | 输出 = `frames_in × 960`（48 kHz），误差 ≤ 1 帧 |
| 采样率 / 声道 | 输出格式 | 48 kHz 单声道 |
| TensorRT 回退 | 是否掉到 ONNX | 生成器回退 = 失败；HuBERT/RMVPE 动态兜底 = 记录 |
| 窗数 / blocks | 分窗几何是否符合预期 | 按几何断言，防路径回归 |
| 墙钟 / 单窗推理耗时 | 成本 | 记录，不设死线 |
| 显存峰值 | 是否接近 OOM | 8 GB 下留余量 |

口径：

- 时长按帧量化：`时长 = frames_in × 20 ms`。解码尾帧补零由 `total_samples` 裁掉（`reports/rvc-fulllength-golden-20261113`），输出再补齐到帧契约。
- TRT 回退分两种。生成器掉 ONNX 算失败；HuBERT/RMVPE 的动态 ONNX 兜底是长文件预期行为（代码确认，`feature_extractor.cpp:524`、`:665`；`reports/rvc-30s-voice-20261115` 实测），一律算失败会冤杀长文件用例。
- 窗数是路径专属、随几何变的断言，不是质量目标。当前几何下 30 s 输入：forced-dynamic 10 s 窗（hop 5 s）为 6 窗；静态定长 T=200（1 s 窗、0.5 s hop）为 63 窗（代码确认，`inferencer.cpp:364-377`、`:417`）。

### 2.2 对齐（核心诊断）

| 指标 | 抓什么 | 建议 |
| --- | --- | --- |
| F0 轮廓延迟 | pitch 是否整体错位 | 目标 0 ms，容差 ±20–30 ms |
| 0 ms 处 F0 轮廓相关 | 对齐后轮廓相似度 | 越高越好，记录 |
| 接缝处 F0 局部阶跃 | 块边界音高跳变 | 记录，与 2.3 接缝同网格 |
| F0 P90 偏差 | 局部跑调 | ≤ 50 音分 |
| 有声帧 IoU | 清辅音 / 静音误判 | ≥ 0.85 |
| 中位 F0 | 整体音高是否合理 | 记录，不单独判失败 |

口径：

- 参考信号：`pitch_shift=0` 时输出轮廓对输入轮廓（或 Golden）。先对齐再比相关；未对齐的帧对帧相关不成立（`reports/rvc-30s-voice-20261115` 已指出）。
- 单位统一音分（cents）。50 音分 = 0.5 半音。
- 全局延迟 0 ms 可能掩盖块边界局部跳变，故加「接缝处 F0 局部阶跃」。

动机（实测）：一次排查中 2 s 窗与 10 s 窗的 F0 轮廓延迟均为 −1000 ms，修复后回到 0 / +20 ms。−1000 ms 恰等于外层 pad `kPad16k=16000`（1 s，代码确认，`inferencer.cpp:22`），即 pitch 切片晚 pad 的失效模式（`inferencer.cpp:427` 注释）。中位 F0 对整体平移不敏感，轮廓延迟才能抓到根因。

### 2.3 音质与接缝

| 指标 | 抓什么 | 建议 |
| --- | --- | --- |
| log-mel 相关 / MAE | 整体音色与频谱 | 对单窗基线，相关 ≥ 0.95 起步 |
| 接缝阶跃 / 谱通量 | 窗边爆音、咔哒 | 接缝处不显著高于窗内中位数 |
| 接缝相位不连续 | 电音、梳状滤波 | 记录，对比不同交叉淡化 |
| RMS 包络相关 / RMS 比 | 音量起伏、呼吸感 | 比值 ±1 dB 内 |
| 峰值 / 削波比例 | 幅度破音 | 峰值 < 0.99，削波 0% |
| 高频能量占比 / 频谱平坦度 | 电音、噪声感 | 记录，对单窗基线 |
| 过零率 / 直流偏移 | 异常波形 | 记录 |

口径：

- 基线按 1 节形态分。
- 破音不等于削波。削波 0% 只保幅度破音；相位咔哒峰值可能正常，须靠接缝阶跃 / 谱通量抓。代码 `limit_peak` 天花板即 0.99（代码确认，`inferencer.cpp:469`），「峰值 < 0.99」主要验证限制器生效，区分度有限。
- 接缝网格与窗内参考带见 4 节。相位不连续用谱通量 / 梳状凹陷做代理。

### 2.4 听感与语义（最终判据）

| 指标 | 抓什么 | 建议 |
| --- | --- | --- |
| ASR CER / WER | 内容是否被破坏 | 对单窗基线不显著变差 |
| 普通话音调错误率 | 跑调 | 时间对齐后统计 |
| ABX / MOS / 偏好 | 电音、破音、自然度 | 固定样本盲听，最终判据 |

口径：ASR 与音调错误率的前置阻塞见 5 节。

## 3 核心消融：单窗 vs 分窗配对差

同模型、同输入，单窗输出与分窗输出逐指标求差，差值即分窗代价，贯穿 2.2 / 2.3 层。

| 消融 | 对照 | 隔离什么 |
| --- | --- | --- |
| 单窗 vs 分窗 | 同模型同输入 | 分窗总代价 |
| 静态 T=200 分窗 vs 整段导出单窗 | 同音色 | 短窗代价 |
| 动态长文件 10 s 窗 vs profile 大窗 | 同模型 | 窗长 / 窗数 |
| 噪声每窗重播种 vs 连续 | 动态分窗 | 噪声错配（电音） |
| 交叉淡化线性 vs 等功率 vs 重叠率扫描 | 同几何 | 拼接方式 |

后三项依赖几何可配置（见 5 节）。噪声每窗重播种只对 full-history 前缀正确，对文件平移窗错配（推断，`inferencer.cpp:888-890`），待消融证实。

## 4 接缝网格与测量方法

- 接缝周期 = `hop_out`。当前 forced-dynamic 为 5 s，静态定长 T=200 为 0.5 s（代码确认，`inferencer.cpp:377-378`）。绝对位置按外层 `pad_out` 裁剪后换算；实测可用谱通量峰反推接缝，再与理论网格核对。
- 窗内参考带：远离接缝的窗中心区域，取指标中位数作基线。
- F0 轮廓延迟：DTW 或互相关求全局滞后；再在接缝网格处求局部音分阶跃。F0 估计沿用 librosa pyin（16 kHz，60–500 Hz，`reports/rvc-30s-voice-20261115`）。
- 谱通量 / 阶跃：接缝 ±N ms 窗对窗内中位数；相邻样本最大跳变沿用 `reports/realtime-pipeline-20261112` 的判据。
- log-mel：STFT 2048 / 512（沿用 30 s 报告）。
- 削波：`|sample| ≥ 0.99` 的样本比例。

## 5 前置阻塞与解除条件

| 阻塞 | 影响 | 解除条件 |
| --- | --- | --- |
| 窗 / pad / hop / 重叠 / 淡化写死 | 3 节几何消融不可跑 | 暴露配置或按引擎 profile 推导（`inferencer.cpp:21-28`、`:377`、`:447`） |
| ASR 进程重启循环 | 2.4 CER / WER 不可跑 | 修复 asr，或改用离线 ASR（`reports/rvc-30s-voice-20261115` 记录） |
| 缺声调标注语料 | 2.4 音调错误率不可跑 | 标注 + 时间对齐；先用 F0 半音 RMSE 顶替 |
| 静态 T=200 无单窗基线 | 1 节基线缺 | 重导出整段 / 大 T / 动态引擎 |
