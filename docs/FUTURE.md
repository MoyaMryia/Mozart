# FUTURE：第一版之后的提升点

状态：待讨论。最后更新：2026-11-14。

本文件只记录已经讨论过、明确推迟到第一版之后的条目。
没有讨论过的想法先不进这里，避免把清单写成愿望池。

| 项 | 场景与动机 | 影响模块 | 前置条件 |
| --- | --- | --- | --- |
| 模型主导参数动态化（多模型适配） | 总方向：凡由模型决定的参数（采样率、帧率、hop、特征维度、上采样比、合成帧数 T、音高量化）都从模型动态读取，据此推导分窗几何、推理模式（整段/动态/分窗）与重采样，不写死常量，换模型即自适应。 | rvc | 以模型能力描述驱动流水线，替代硬编码假设；跨架构 golden 对拍验证。 |
| 在线参数调整（SetParams） | 调 `pitch_shift`、`index_rate` 时不中断音频。第一版走 `StopStream` → `StartStream`。 | rvc、daemon | 控制面加命令；C++ 在块边界读参数快照；防抖与状态回报。 |
| 回声抑制 / 回声消除（AEC） | 扬声器播出的变声或播报被麦克风再次拾取，形成回声甚至啸叫。 | pre、core | DSP 阶段接口预留参考帧；播放侧提供带时间戳的最终混音参考环；板端测 ERLE（回声抑制量）和双讲（双方同时说话）。 |
| 降噪器切换 | 默认继续用 WOLA；保留切换能力，便于以后对比 DTLN、RNNoise。 | pre | 统一降噪器接口；固定输入逐阶段对拍；板端 CPU 与延迟预算。 |
| 共享内存环形缓冲 | 已评估：当前 20 ms 帧率下 Unix 数据报足够，暂不采用；只有实测抖动或 CPU 压力不够时才做。 | core、pre、rvc | 跨进程 SPSC（单生产者单消费者）、丢最旧、生命周期管理。 |
| F0 中值滤波（`filter_radius`） | 旧 C++ 只保存参数、未参与计算。v1 不暴露死参数；保留为提升项，推迟实现。 | rvc | 中值滤波实现；与 Python 参考逐帧对拍；实现后暴露到 `StartStream`。 |
| 播报经变声输出（同音色，占 GPU） | v1 播报用参考音色直播、扬声器分时已做；播报经变声用同一目标音色、接入 GPU 仲裁推迟。 | daemon、pre、rvc | 播报喂 RVC 通道；GPU 仲裁含播报活动；板端验证切换延迟。 |
| 播报与实时同时混音 | v1 分时（播报时静音实时、播完恢复）；播报与实时同时混音推迟。 | daemon、pre | 板端测混音可懂度与延迟。 |
| 提前断句翻译（stable_clauses）与断句模型 | 流式识别中提前切稳定子句翻译以降低延迟。旧实现为可选、演示默认关，第一版只做整句翻译。规则版（stable_cut）与可选 NNSplit 断句模型一并推迟。 | language | 第一版整句翻译稳定后；子句状态机、更正处理、子句汇总搬 Rust 并对拍；断句模型另需 onnxruntime（ort）与模型文件。 |
| 灵活变速（flexible tempo） | 播报按时长比例（预测播报时长 / 源时长）与积压反馈选 1.0–1.5 倍速、保留音高。第一版播报原速。 | language、pre | 播报播放路径定（含共用扬声器仲裁）；时长模型按新目标音色重标定（旧为 Qiqi + PocketTTS）；控制逻辑与 4 参数时长模型搬 Rust；拉伸用现成 C 库 libmozart-tempo。 |
| 离线推理分块流式 | v1 整段批处理，内存由 300 s 时长上限兜底。先板端实测整段 F0 耗时与取消等待；若等待过长、或要支持远超 300 s 的长文件，再做分块流式（边收帧边算、整段 F0/归一化改流式）进一步限内存。 | rvc、daemon | 板端实测整段 F0 耗时与取消等待（当前未测，作为是否分块的依据）；流式 F0 与归一化；与整段输出逐段对拍；板端内存与音质验证。 |
| 音频设备热切换 | v1 换设备由 daemon 重启 pre（断流约 1–2 s）。热切换在 pre 采集/播放循环边界换 ALSA 句柄，不断流、不重启进程。 | pre | 采集/播放线程支持循环边界换设备句柄；DSP 状态重置规则；新设备打开失败回退；板端验证切换无杂音。 |
| RVC 参数纳入 config set | `config set` 当前只支持 `pre.capture_device` / `pre.playback_device`。RVC 参数（`pitch_shift`、`index_rate`、`rms_mix_rate`、`protect`、`f0_method`）只能改 TOML 后 `restart rvc`。扩展 `config set` 支持 RVC 键。 | daemon、core、ctl | `set_key` 放开 RVC 键白名单；会话参数（R）经 `StopStream` → `StartStream` 下发，重启键（S）返回 `restart_required`；与 SetParams 协同。 |
| RVC 配置热重载 | 改 RVC 参数当前需 `restart rvc`，断流约 1–2 s。热重载不重启进程，重读 TOML 并应用会话参数。 | rvc、daemon | 依赖 SetParams 的块边界参数快照；daemon 加热重载命令；区分可热更键（会话参数）与需重启键（模型、socket）。 |
| protect 与 rms_mix_rate 实时对齐 | `protect`、`rms_mix_rate` 只在文件链路生效，实时链路不应用；实时还跳过峰值归一、48 Hz 高通、限幅。文件与实时听感不一致。 | rvc | 实时链路补应用辅音保护与音量包络；评估实时线程开销；板端对比文件与实时输出。 |
| 重采样抗镜像滤波 | 模型原生采样率转 48 kHz 用纯线性插值，无抗镜像滤波。非 48 kHz 模型（如 40 kHz）上采样引入高频镜像，音质受损。 | rvc | 加抗镜像 / 抗混叠滤波（多相或 FIR）；非 48 kHz 模型频谱对拍。 |
