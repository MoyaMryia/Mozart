## 功能验收

以下项目以人能直接听到、看到或操作到的结果为准。测量记录写入 `reports/`。
数值门槛来自评分标准和产品目标；未标注来源的为本次重写提出的门槛，需实测确认。

### 实时变声

- 对着麦克风说话，扬声器持续输出目标音色；不中断、不爆音、无明显机械感。
- 首帧出声不超过 400 ms（旧启动预算；旧实测 320 ms）。
- 稳态推理块时延不劣于旧基线（固定模型与配置；中位 88 ms、P95 93 ms）。
- 连续 30 分钟不丢帧（建议门槛）。

### 翻译字幕

- 说话后，网页按句显示原文和译文；断线后能自动恢复。
- 句末后 1–2 秒内出现译文。
- 每个输入都有结果或失败记录；错误和未翻译项逐条列出。

### 翻译播报

- 译文用参考音色播出（v1 继承旧播报；经变声同音色见 FUTURE）；按句序、不丢句。
- 播报队列有上限，积压时不无限等待。
- 句末到第一声播报的延迟门槛待定。
- 播放关系（分时或混音）见 [SPEC-05-language.md](SPEC-05-language.md)。

### 文件转换

- 用 CLI 提交音频文件（`file submit`）能得到变声结果并取回（`file fetch`）；v1 用 CLI 验收，网页上传下载归 web 适配器（后续）。
- 任务可取消；每个输入都有结果或明确失败原因。
- 长文件不会耗尽内存。

### 音频直出

- 麦克风声音经降噪后直接播放；端到端不超过 10 ms（评分标准优秀档），听感无延迟、无抖动。

### 系统级

- 一次采集同时供变声、字幕和翻译播报使用，互不中断。
- 扬声器切换输出时无爆音。
- 连续运行 24 小时无崩溃、无内存泄漏、无性能衰减（评分标准优秀档）。
- 全部计算在设备本地完成；峰值内存不得超过设备可用内存，具体预算待定。
- 前端能完成启动、切换、查看状态和停止。
