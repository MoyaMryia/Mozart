# language：语言服务

状态：讨论中。

## 方向

旧实现的 Python 服务全部用 Rust 重写，Python 不进入运行时。

- Rust：识别编排、字幕桥、翻译调度、质量检查、翻译播报调度、投递队列、变速、启动监督。
- C++：识别与合成的模型推理，经 sherpa-onnx 的 C/C++ 接口调用；翻译模型仍作为独立进程。
- 翻译播报经变声链路输出，用同一目标音色，替代旧的参考音色播报；分时或同时混音待定。

## 待讨论

- sherpa-onnx 的接入形态：Rust 直接 FFI，还是独立 C++ 推理进程。
- 同音字纠错依赖拼音和分词，Rust 侧结果需要和旧实现逐条对拍。
- 翻译模型与运行方式。
